정적 장애물 preset 저장 구조

generated/<suite>.json 하나에 해당 suite의 YAML 원문과 suite_manifest.json
원문을 함께 저장한다. entries의 키는 기존 파일명이며, 각 항목은 UTF-8 원문
text와 그 원본 바이트의 SHA-256을 가진다. 검증 기록과 승인 여부는 원본 그대로다.

기존 11개 suite의 YAML 1,050개와 manifest 11개를 카탈로그 11개로 통합했다.
배치 내용 중복은 없었으므로 배치를 삭제하지 않았다. 기본 자동 pair 선택
후보 54개와 정렬 순서, 명시적 preset 선택, 기존 계획표의 파일 해시를 유지한다.

기존 명령은 같은 논리 경로를 사용한다. 예:
  --static-preset scenario_runner/config/static_scenario_presets/generated/static_rot90_20261005/static_rot90_20261005_attempt_002.yaml

runner와 관련 도구는 utils/static_preset_store.py를 통해 원문을 읽는다.
읽을 때 낱개 파일을 디스크에 다시 만들지 않는다. 카탈로그로 통합된 경로는
운영체제의 개별 파일이 아니므로 별도 Python 도구에서는 Path.read_text 대신
static_preset_store.read_text/read_bytes를 사용한다.
기존 외부 YAML 파일과 새로 생성한 loose preset도 계속 사용할 수 있다.

편집기 저장과 수동 후보 승인은 해당 카탈로그를 원자적으로 갱신한다.
기존 계획표가 기록한 원본 SHA는 바꾸지 않으므로 내용을 수정하면 그 계획표의
해시 검사가 원래처럼 변경을 감지한다. text만 편집해 SHA 검증을 우회하지 않는다.

새로 생성한 suite도 통합하려면 AIM2026 환경을 불러온 뒤 실행한다:
  python3 -m scenario_runner.tools.compact_static_presets SUITE_NAME --remove-loose

이 명령은 저장한 카탈로그의 모든 원문 해시를 확인한 후 낱개 파일을 제거한다.
--remove-loose를 생략하면 카탈로그만 만들고 낱개 파일은 남긴다.
동일 경로에 낱개 파일이 있으면 그 파일을 우선 읽는다.
