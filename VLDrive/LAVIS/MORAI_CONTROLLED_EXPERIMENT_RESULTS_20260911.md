## 결론부터

이번 결과는 **“정답이나 timestamp가 뒤섞여서 학습이 망가졌다”**, **“기존 특징에는 좌우 구분 정보가 전혀 없다”**, **“출력층 초기화 또는 FP32만으로 고칠 수 있다”**는 설명을 지지하지 않는다.

반면 **중요하지만 드문 상황의 학습 비중**, **여러 상황을 함께 구분하는 학습의 안정성**, **정지 상태에서 신호색을 읽는 현재 특징/분류기의 약한 구분력**은 실제로 문제가 남아 있다. 이들이 각각 얼마나 기여하는지는 아직 단일 원인으로 확정하지 못했다. 특히 출력층만 학습한 결과로 encoder, connector 또는 auxiliary loss 중 하나를 고장 부위로 단정하면 안 된다.

기존 데이터·vision encoder·downstream 모델은 보존했다. 이번에 학습한 것은 별도 복사본인 진단용 출력층/신호 분류기다. 새 모델 구조를 넣거나 진단 가중치를 실제 주행 모델로 교체하지 않았다. 아래 수치는 기존 **train 자료의 오프라인 진단**이며 validation 주행 성능이나 closed-loop 성공률이 아니다.

## 2. 기존 모델의 문제가 전체 감독 위치에서도 재현되는가?

FDE는 **2.5초 뒤 마지막 예측 위치와 실제 위치 사이 거리**, ADE는 0.5~2.5초의 다섯 위치 오차 평균이다.

| 실제 미래 궤적 기준 그룹 | 감독 위치 수 | ADE | FDE |
| --- | ---: | ---: | ---: |
| 정지 | 4,572 | 0.0054m | 0.0077m |
| 직선 이동 | 1,542 | 0.8378m | 1.8426m |
| 좌회전 | 387 | 1.7654m | 3.9574m |
| 우회전 | 495 | 1.9801m | 4.3534m |
| 전체 | 6,996 | 0.4260m | 0.9381m |

전체의 약 65%가 정지라 전체 평균은 좋아 보인다. 회전 882개만 보면 FDE **4.1797m**이고, 종점 제곱오차의 **92.2%가 옆 방향**이다. 좌회전 387개는 모두 예측 lateral 부호가 반대였다. 마지막 frame만 집계해서 생긴 착시는 아니다.

첫 녹색 네 frame은 각각 두 context에서 실제 loss 대상이었다. 이 여덟 예측의 마지막 이동 거리는 평균 **0.0010m**, 실제 GT는 평균 **9.2475m**였다. 즉, 첫 녹색이 학습에 아예 안 들어간 것이 아니라, **들어갔는데도 출발 궤적을 맞히지 못했다**.

현재 빨간불이지만 2.5초 안에 녹색으로 바뀌어 실제 미래 GT가 이동하는 경우도 분리했다. 고유 66 frame/147 감독 위치이며, 이를 평가에서 제외해도 전체 FDE는 **0.938→0.871m**로만 내려가고 회전 오차는 그대로다. 이것만으로 회전 실패를 설명하거나 실제 미래 GT를 임의 수정할 근거는 없다.

## 3. 회전: 같은 구조가 기존 특징에서 배울 수 있는가?

### 3.1 32개 window에서 기존 출력층과 재초기화 출력층 비교

정지·직선·좌회전·우회전 anchor를 각각 8개씩 GT와 시간 순위만으로 선정했다. 각 window의 11개 위치 모두를 학습하므로 총 352개 감독 위치다. 실제 위치별 구성은 정지 85/직선 124/좌 72/우 71개다. 첫 녹색 네 frame은 이 소규모 집합에 없다.

구조는 기존 `2048 → 2048 → 10`, ReLU를 그대로 사용했다. 입력은 고정된 기존 LLM 특징이다. 동일 sample 순서, L1, AdamW, LR 1e-4, weight decay .06, clipping 10, 1 window/update, 최종 1,000 update로 고정했다. 아래 초기화 비교는 upstream 전체 모델 재학습이 아니다.

| 조건 | 전체 좌표 L1 | 회전 FDE | 결과 |
| --- | ---: | ---: | --- |
| 기존 모델, 추가 학습 전 | 0.6332m | 4.3685m | 기준 |
| 기존 출력층 이어 학습, BF16 | 0.6855m | 4.0907m | 엄격 암기 기준 실패 |
| 같은 구조 새 초기화, BF16 | 0.6716m | 4.1577m | 실패 |
| 기존 출력층 이어 학습, FP32 | 0.6698m | 4.1157m | 실패 |
| 같은 구조 새 초기화, FP32 | 0.6708m | 4.1693m | 실패 |

FP32 조건은 BF16 조건과 **동일하게 반올림된 초기 parameter 값**에서 시작했다. 따라서 초기값 차이를 정밀도 효과로 섞지 않았다. 그래도 실질적인 회전 개선은 없었다. 단, 출력층 계산만 FP32로 바꾼 것이며, 이미 생성된 frozen 특징이나 과거 RoPE의 영향을 없앤 전체 FP32 모델 실험은 아니다.

사전 기준은 전체 L1 <0.05m, 회전 FDE <0.5m, 회전 방향 일치 ≥95%, 정지 FDE <0.1m였다. 좋은 중간 step을 골라 성공이라고 하지 않고 최종 1,000회를 판정했다.

기존 출력층은 학습 도중 좌회전 쪽으로 치우쳤다가 우회전 쪽으로 바뀌는 양상을 보였다. 예를 들어 step 500은 좌 0%/우 69%, step 600은 좌 0%/우 100%, step 1,000은 좌 62.5%/우 0%다. **안정적으로 수렴한 뒤 더 이상 표현할 수 없는 상태라고 입증된 것은 아니다.** 재초기화 모델도 시작 L1 4.3081m에서 0.6716m까지 배웠으므로, 아무 학습도 없었던 것은 아니다.

### 3.2 한 회전씩, 그리고 두 회전을 같이 학습

32-window 결과 후, 동일한 구조와 원래 출력층 초기값으로 실행한 탐색적 대조다. 두 구간은 우회전 anchor 2850, 좌회전 anchor 2980으로 고정했다.

| 학습 자료·방식 | 최종 update / window 노출 | L1 | FDE | 좌우 방향 |
| --- | ---: | ---: | ---: | --- |
| 우회전 한 구간 | 1,000 / 1,000 | 0.05370m | 0.12472m | 우 100% |
| 좌회전 한 구간 | 1,000 / 1,000 | 0.05419m | 0.06725m | 좌 100% |
| 좌·우 두 구간 순차 학습 | 1,000 / 1,000 | 0.23631m | 0.94653m | 양쪽 100% |
| 좌·우 두 구간 한 batch에서 학습 | 500 / 1,000 | 0.21421m | 0.85448m | 양쪽 100% |

두 구간에 대한 기존 모델 FDE는 원래 1-window 평가 모양에서 **4.2777m**였다. 방향 판정은 마지막 lateral의 부호가 맞고 크기가 0.5m 이상인지를 뜻하며, 궤적 전체가 정확하다는 뜻이 아니다.

중요한 해석 제한:

- **한 구간 단독 결과만으로 입력을 잘 읽었다고 할 수 없다.** 입력을 무시하고 그 구간의 좌표별 중앙값만 내는 상수 예측도 L1이 좌 0.03387m/우 0.05111m로 단독 MLP보다 좋다. 한 구간 결과는 해당 평균 궤적 쪽으로 출력을 바꿀 수 있다는 확인에 가깝다.
- 반면 두 구간을 함께 학습한 모델은 **서로 반대인 두 방향을 모두 구분했다.** 두 구간에 하나의 공유 상수 궤적만 내는 비교는 L1 0.9985m/FDE 4.2985m이며 방향 기준을 하나도 통과하지 못했다. 기존 특징에 그 두 구간을 구분할 정보가 전혀 없거나, 같은 구조가 원천적으로 좌우를 표현하지 못한다는 설명은 약해졌다. 새로운 회전이나 위치와 무관한 회전 의미를 배웠다는 증명은 아니다.
- 단독 조건도 최종 L1 <0.05m를 근소하게 넘었고, 두 구간 조건은 L1 및 FDE <0.5m 기준을 통과하지 못했다. 따라서 “정확한 암기 완료”는 아니다.
- 32개 조건은 각 window를 약 31~32회, 두 구간 조건은 각각 500회 봤다. **표본 수와 표본당 반복 횟수가 동시에 달라** 단순히 표본 구성만이 원인이라고 결론 내릴 수 없다.
- 순차/동시 조건은 총 노출은 같지만 optimizer update 수가 다르다. 누적 learning rate·weight decay와 gradient 평균 방식도 달라, batch size만의 인과 효과는 아니다.
- BF16에서 batch 모양에 따른 예측 차이가 최대 0.0625m였다. 표는 가능한 한 원래 1-window 평가 모양으로 통일했다. 동시 batch 그대로 집계하면 FDE는 0.85555m로, 결론은 같다.

**회전에 대한 현재 결론:** 데이터를 더 모아야만 비로소 회전할 수 있는 상태는 아니다. 기존 특징과 구조로도 소수 구간의 양방향 학습은 가능하다. 그러나 여러 구간을 함께 정밀하게 맞히는 데는 실패했고, 학습량·표본 구성·최적화 조건·upstream 특징의 구분력 중 기여도를 더 나눠야 한다. 출력층 초기화나 출력층 BF16 정밀도 하나만을 주원인으로 지목할 근거는 약해졌다.

## 4. 신호: 라벨을 정리하거나 희귀 표본을 강조하면 해결되는가?

### 4.1 중요한 순간 자체가 매우 드물다

불확실한 라벨 182개를 제외한 유효 train frame 3,170개 중, 현재 속도 ≤0.001m/s 기준:

| 상태 | frame 수 |
| --- | ---: |
| 정지 + 빨간불 | 2,042 |
| 이동 + 빨간불 | 336 |
| 정지 + 녹색 | **8** |
| 이동 + 비적색 | 784 |

정지-녹색 8개는 독립 사건 8개가 아니라 **네 번의 녹색 전환에서 각 두 frame**이다. 정지-빨간불 대 정지-녹색은 **255.25 : 1**이다. 전체 frame을 많이 반복해서 보는 것과 출발에 필요한 다양한 사례를 충분히 배우는 것은 다르다.

### 4.2 같은 신호 분류기를 세 방식으로 학습

기존 frozen vision token과 원래 `256 → 2` 분류기를 사용했다. seed 607/608/609, 원래 초기값·batch 순서·optimizer·최종 epoch 100을 맞췄다. 182개 mask는 정답색을 바꾼 것이 아니라 unknown 70/composite 112개의 loss를 제외한 것이다.

| 조건 | 유효 3,170개 정확도 | 첫 녹색 네 사건 인식 | 정지 중 빨간불을 비적색으로 오인 |
| --- | ---: | ---: | ---: |
| 기존 라벨로 분류기 추가 학습 | 98.30~98.36% | 모든 seed 0/4 | 0/2,042 |
| 불확실한 182개만 제외 | 98.93~99.05% | 모든 seed 0/4 | 0/2,042 |
| 제외 + 상태별 희귀도 역비례 가중치 | 92.08~92.49% | 1/4, 1/4, 3/4 | 156~168/2,042, **7.64~8.23%** |

즉, **전체 정확도가 99%여도 가장 필요한 첫 녹색은 전부 틀릴 수 있다.** 라벨 제외만으로 출발 인식은 고쳐지지 않았다. 단, 이 실험은 분류기만 학습했으므로, 라벨을 바로잡고 encoder 자체를 다시 학습했을 때의 효과까지 부정하지 않는다.

희귀도 가중치는 정지-녹색을 약 99배 강조했다. 일부 첫 녹색을 맞히기는 했지만 빨간불 오인이 늘었다. 특히 frame 2791 사건은 녹색 3초 전부터 녹색으로 잘못 판단했다. 따라서 단순히 녹색 응답 비율이 오른 것을 신호 전환을 잘 읽은 성공으로 볼 수 없다. 이 진단용 가중치를 실제 모델에 적용하지 않았다.

### 4.3 신호 정보가 token에서 완전히 사라졌는가?

ego 위치·heading·속도가 같은 네 신호 사건에서 직전 빨강 두 장/직후 녹색 두 장, 총 16개를 비교했다. 원본 이미지의 실제 램프 색과 native/gRPC 시각을 확인한 표본이다.

작은 선형 분류기는 동일한 16개를 학습·평가하면 traffic/waypoint/전체 token 모두 **16/16**을 외웠다. 하지만 한 사건 전체를 학습에서 빼고 그 사건의 색을 읽게 하면 traffic token은 **9/16**, 나머지는 **8/16**이었다. encoder는 이미 이 사건들을 본 모델이므로 이것도 독립적인 전체 모델 validation이 아니라, 특징에서 색 정보를 읽는 방식에 대한 진단이다.

**신호에 대한 현재 결론:** 현재 특징에서 색 관련 차이가 전혀 없다고 할 수는 없다. 그러나 정지 상태의 빨강/녹색을 현재 readout이 안정적으로 구분한다고 보기 어렵고, 중요 사례의 255배 빈도 차이가 학습에 영향을 준다. 단순 mask나 강한 가중치만으로는 안전하게 해결되지 않았다. 입력 crop/해상도 개선, 다양한 정지-녹색 사례, encoder의 신호 학습은 서로 구분해서 검증해야 한다.

근거: [신호 실험 전체 결과·조건·한계](outputs/diagnosis_controlled_experiments_20260911/traffic_report.md).

## 5. 이번에 확정하지 않은 것과 다음 순서

이번에는 auxiliary loss를 하나씩 제거하는 전체 학습, vision encoder 재학습, 전체 6,996 위치의 원래/균형 sampling 비교를 실행하지 않았다. 마지막 항목은 소규모 암기 gate 통과 후 진행하기로 사전 계획했으나 gate가 실패해 보류했다. 대신 원인 분리용 정밀도·단독·두 구간 대조까지만 실행하고 종료했다.

따라서 이번 결과를 **“loss A의 gradient가 주원인으로 확정됐다”**, **“VE 재학습은 불필요하다/반드시 필요하다”**, **“데이터만 늘리면 해결된다”**, **“논문 구조가 틀렸다”**로 확대하면 안 된다.

앞선 직접 backward 검사에서는 최종 모델의 정지/우회전/좌회전 세 입력에서 주행 gradient norm이 2.789/19.196/19.663, 복원 gradient가 0.00408/0.00876/0.01000이었다. 이 세 입력에서는 복원이 전체 주행 학습을 압도하지 않았다. 반대로 초기 pilot의 selector에서 관측한 불균형까지 없었다는 뜻은 아니다. 이번 출력층-only 학습에는 현재의 reconstruction gradient 자체가 없으므로, 여기서도 회전 오차가 남았다는 사실은 **“지금의 보조 loss 경쟁 하나만 제거하면 해결된다”**는 설명을 약화한다. 단, frozen 특징에 남은 과거 학습의 영향은 분리하지 못했다. 근거: [앞선 loss별 실측과 적용 범위](MORAI_DATA_SUFFICIENCY_ANALYSIS_20260911.md).

다음 실험은 새 구조 도입보다 다음 순서가 합리적이다. 아직 실행한 결과가 아니다.

1. 회전은 동일 32개 자료와 구조를 유지하고, 표본당 노출 횟수를 맞춘 비교를 먼저 한다. 학습률 감소와 gradient 평균 방식은 별도 조건으로 나눠, 현재의 좌우 편향 진동이 줄어드는지 본다. “두 구간은 500회, 32개는 31회” 차이를 먼저 제거한다.
2. 작은 집합에서 안정적 학습 조건이 확인되면 원래/균형 sampling을 같은 update·초기값으로 비교한다. 회전 개선과 정지 성능 저하를 함께 평가한다.
3. 실제 connector/LLM 학습 graph에서는 앞선 세 입력 진단을 확대해, 학습 과정의 여러 시점·같은 minibatch에서 loss별 shared-parameter gradient 크기·방향과 합산 후 방향을 측정한다. 출력층-only 실험에는 upstream auxiliary loss gradient가 오지 않으므로, 이번 결과만으로 그 경쟁의 원인을 판정할 수 없다.
4. 신호는 신호색이 보존되는 입력과 정지 중 색 전환 사례를 확보한 뒤, 수정 라벨로 encoder도 학습하는 대조가 필요하다. 출발 인식률만 보지 말고 정지-빨간불 오인율을 반드시 같이 본다.

요약하면, **자료 연결의 광범위한 오류는 발견하지 못했고, 소수 회전은 기존 구조로 구분 가능했다. 남은 핵심은 여러 상황을 함께 정밀하게 배우는 학습 조건과, 매우 희귀한 정지-녹색을 현재 표현에서 안정적으로 구분하지 못하는 문제다.** 기존 모델은 교체하지 않았으며 이번 진단 실험은 종료했다.
