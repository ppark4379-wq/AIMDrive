# MEFA 과거 정보 효과 재확인

> 이후 F: 연결이 복구되어 새 20개 주행/160개 프레임 확대 검증을 완료했다.
> 최신 결과는 `outputs/logs/mefa_history_validation_20_drives/REPORT.md`와
> `mefa_result.json`에 있다. 정상 과거의 상대 오차 감소는 0.03834%,
> delta Lrec는 +0.0001204595, 주행 단위 bootstrap 95% 구간은
> [+0.0001029986, +0.0001377260]이다. 20개 주행 모두 평균 delta가 양수였다.
> 아래 내용은 드라이브 미연결 당시 기존 2개 주행 재확인의 기록이다.

추가 학습 없이 `connector_mefa_dynamic_anneal/model-last.pt`를 strict load하여
모든 가중치를 고정했다. 현재 프레임, CCDP 마스크, 선택 인덱스, 복원 정답이
같은 것을 확인하고 정상 과거/과거 0만 비교했다. LLM 또는 CCDP 순위 비교는 하지 않았다.
평가 후 parameter 수정·gradient가 없고 원본 checkpoint SHA256도 그대로임을 확인했다.

## 실행 결과

실제 평가한 데이터는 기존 validation의 동적 장애물 1개 주행과 정적 장애물 1개 주행이다.
각 주행에서 8개씩 총 16개 현재 프레임을 평가했으며, 모두 과거 10프레임이 확보되어 있다.
이는 새 test set 평가가 아니라 동일 checkpoint의 기존 validation 결과 재확인이다.

| 조건 | 전체 평균 Lrec |
|---|---:|
| 정상 과거 | 0.318014523 |
| 과거 특징 0 | 0.318084842 |
| 차이 (0 − 정상) | +0.000070319 |

정상 과거가 평균 복원 오차를 약 **0.0221%** 줄였고, 16개 중 11개 프레임에서 우세했다.
주행별 delta도 dynamic +0.000064876, static +0.000075761로 둘 다 양수였다.
이 값은 encoder 특징 공간의 제거된 토큰·채널 평균 MSE다.

**해석:** 이 작은 표본에서 과거 특징의 복원 기여가 관측되지만, 크기가 매우 작다.
MEFA 성능이 충분히 검증됐거나 일반화되는 이점이 있다고 결론 내릴 수 없다.
독립 주행이 2개뿐이므로 신뢰구간은 제시하지 않았다. 다른 seed 학습과의 비교도 아니다.

## 확대 검증 상태

기존 6개 train/validation 주행을 제외하고 동적/정적 각각 10개 주행을 선택하는
평가 전용 실행기를 준비했다. 주행별 평균과 카테고리별 paired episode bootstrap을 지원한다.
추가 테스트를 포함한 9개 검사가 통과했다.

하지만 이번 실행 시점에는 F: 드라이브가 보이지 않아 원본 데이터와 encoder 가중치를
읽을 수 없었다. 확인 가능한 파일시스템 드라이브는 C:와 Z:였다.
따라서 **20개 주행/160개 프레임의 확대 평가 결과는 아직 없다.**
`F:/dataset_label`을 다시 연결한 뒤 README의 확대 검증 명령으로 진행할 수 있다.

결과 파일: `VLDrive/outputs/logs/mefa_history_cached_recheck/mefa_result.json`.
