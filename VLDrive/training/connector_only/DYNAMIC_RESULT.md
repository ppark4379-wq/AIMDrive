# 동적 CCDP 선택 검증 — 2026-10-05

## 결론

Gumbel 노이즈 감소 후 1개 토큰만 남는 붕괴는 이 pilot에서 사라졌다.
동적 argmax 선택을 유지했으며 고정 개수 top-k로 바꾸지 않았다.
학습된 선택은 동일 개수의 무작위 선택보다 평균 복원 오차가 0.42% 낮았다.
다만 검증 2개 주행/16개 현재 프레임, 단일 학습 seed의 작은 결과다.
목표 30%에 대한 검증 유지 비율 편차와 선택의 작은 성능 차이는 추가 검증이 필요하다.

## 공정한 비교 조건

- 기존 pilot과 동일한 encoder, 특징 캐시, 주행 분할, 초기 seed 607,
  optimizer/lr, loss, 모델 구조 및 10 epoch/320 update 사용
- 기존 가중치에서 이어 학습하지 않고 동일 초기 seed로 처음부터 학습
- Gumbel noise scale만 update 0~256에 1에서 0으로 선형 감소
- 마지막 64 update는 noise=0, temperature는 기존 1 유지
- 원본 pilot 가중치와 결과는 보존; 새 출력은 `outputs/logs/connector_mefa_dynamic_anneal/`
- `cache_source.json`은 복사한 원본 특징 추출의 provenance이며 새 학습 설정은
  체크포인트의 `config` 및 `dynamic_anneal.json`에 저장됨

## 1. 평가에서 적절한 수의 토큰을 남기는가?

| 지표 | 기존 pilot | 노이즈 감소 |
|---|---:|---:|
| 검증 argmax 유지 비율 | 0.9434% | 38.2075% |
| 검증 현재 프레임의 선택 개수 | 모두 1개 | 10~85개, 평균 40.5개 |
| 1개만 유지한 검증 현재 프레임 | 16/16 | 0/16 |

학습 완료 모델을 고정하고 동일 입력에서 `gumbel_noise_scale=0`의 학습 마스크와
평가 argmax 마스크를 비교했다. train 32개와 validation 16개 시퀀스의 모든 프레임에서
불일치 원소는 0이었다. 빈 프레임 보호 처리에 의해 구조된 현재 프레임도 0개였다.

동일한 최종 가중치의 argmax 유지 비율은 train 31.7512%, validation 38.2075%였다.
마지막 epoch의 학습 도중 평균 35.3479%와는 가중치와 집계 시점이 다르다.
최종 train/validation 차이는 서로 다른 입력 데이터에 대한 값이며 선택 규칙 불일치가 아니다.

판정: **붕괴와 학습/평가 선택 규칙의 불일치는 해소됨. 목표 비율 준수는 부분적.**
검증 평균은 목표보다 8.2 percentage points 높고 선택 개수 분산도 크다.
검증 keep 확률 범위가 약 0.474~0.542로 임계값 근처에 있어 안정성 검증도 필요하다.

## 2. 같은 개수 무작위 선택보다 복원에 도움이 되는가?

각 프레임의 실제 동적 선택 개수를 그대로 사용해 무작위 마스크를 생성했다.
무작위 seed 0~19에 대해 16개 현재 프레임, 총 320개의 paired 비교를 수행했다.
가중치·현재 입력·정상 과거를 고정하고 양쪽에서 공통으로 제거된 토큰만 평가했다.
이로써 서로 다른 정답 토큰 난이도가 비교에 직접 섞이는 것을 줄였다.

| 조건 | 공통 제거 토큰의 평균 MSE |
|---|---:|
| 학습된 동적 선택 | 0.317775762 |
| 같은 개수 무작위 선택 | 0.319118408 |
| 무작위 − 학습된 선택 | +0.001342646 |

무작위 대비 상대 오차 감소는 0.4207%다.
무작위 seed 평균 기준으로 16개 현재 프레임 중 12개에서 학습된 선택이 우세했다.
주행별 delta는 dynamic +0.002112354, static +0.000572938로 둘 다 양수다.

판정: **이 검증 표본에서는 작지만 평균적인 이점이 관측됨.**
320개 비교는 320개 독립 장면이 아니다. 무작위 선택으로 별도 학습한 모델도 아니므로
일반적인 학습 방식 우월성이나 통계적으로 확정된 성능 향상으로 해석하지 않는다.

## 부가 MEFA 비교

정상 과거 Lrec 0.318014523, 과거 0 Lrec 0.318084842,
delta +0.000070319. 16개 중 11개에서 정상 과거가 우세했다.
이 값은 전체 제거 토큰 기준으로, 위의 공통 제거 토큰 MSE와 평가 대상이 다르다.
효과가 작으므로 MEFA가 충분히 학습되었다는 결론은 내리지 않는다.

## 산출물과 확인

- `model-last.pt`: 새 connector 가중치, optimizer/RNG, 설정과 데이터 hash
- `evaluation-argmax-diagnostic.json`: 동일 개수 무작위 선택 320회 비교, 과거 유무 비교
- `selection_consistency.json`: 최종 가중치의 마스크 일치 및 선택 확률/개수
- `metrics.jsonl`: 10 epoch 학습 곡선, 노이즈 scale과 gradient
- `run_verification.json`: checkpoint와 코드 hash, 검사 결과

체크포인트 strict reload 후 검증 Lrec는 마지막 epoch 평가와 일치했다.
노이즈 schedule 끝점·0 noise 마스크 일치·gradient 전달 검사를 포함해 7개 테스트가 통과했다.
