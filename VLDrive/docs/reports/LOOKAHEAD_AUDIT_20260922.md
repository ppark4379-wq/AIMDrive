# 가까운 조향 목표점 원인 분석 — 2026-09-22

## 결론

현재 실제 속도 약 1m/s와 `clip(.65×속도, 2, 30)` 설정 때문에 목표 거리가 2m로 고정됐다. 최신 실제 주행 로그의 471회 제어 계산 전부 목표 거리가 2m이고, 모두 예측 당시 원점과 첫 번째 모델 waypoint를 연결한 선분에서 목표점을 만들었다. 코드가 설정대로 동작한 결과이며, 희소한 신경망 waypoint에 대해 선택한 최소 거리와 경로 구성의 적합성 문제다.

화면 차량은 원점을 중심으로 길이 4.5m(전방 끝 +2.25m)로 그린다. 그래서 반경 2m 목표점이 차체 안에 보인다. 제어기의 후륜 기준 가정과 표시 차체 중심 기준이 정합되지 않았다. 실제 센서 기준점이 어디인지 확정하지 않은 상태이므로 화면만으로 실차 범퍼와 목표점의 물리적 위치 관계를 단정할 수는 없다.

이번 작업에서는 코드와 config를 수정하지 않았다. 로그 분석과 같은 입력의 거리 변경 재계산만 수행했다.

목표 거리 2m는 경로를 따라 2m 이동한 거리가 아니라, 후륜으로 가정한 기준점에서 목표점까지의 직선 거리다. `max_lookahead_m=30`은 상한이며 평소 30m를 보는 설정이 아니다. navigation 안내 30m와도 별개다.

속도가 `2/.65 = 3.0769m/s`(약 11.08km/h)를 넘어야 목표 거리가 2m보다 커진다. 현재 목표 속도 상한 1m/s 조건에서는 사실상 최소값이 계속 적용된다. 최대 거리만 늘리거나 .65를 조금 바꾸는 것으로는 이 구간 목표점이 멀어지지 않는다.

## 왜 문제가 될 수 있는가

Pure Pursuit 식은 `휠각=atan(2×wheelbase×목표점 좌우거리 / 목표점 거리²)`다. 같은 크기의 횡방향 오차는 가까운 목표점일수록 크게 조향에 반영된다. wheelbase=3m, 목표점 좌우거리=.1m를 고정한 계산 예시는 다음과 같다.

| 목표점 직선 거리 | 계산 휠각 |
|---|---:|
| 2m | 8.5308° |
| 4m | 2.1476° |
| 5m | 1.3748° |

이는 같은 횡방향 거리 조건의 예시이며, 실제 곡선에서 목표점을 멀리 잡으면 언제나 조향이 작아진다는 뜻은 아니다. 실제 목표점의 좌우거리도 경로에 따라 바뀐다. 짧은 lookahead가 휠베이스보다 작다는 이유만으로 수학적 오류인 것도 아니다. 이번 문제는 저속 상한·희소한 예측 점 간격·직선 보간·기준점 가정이 결합된 것이다.

이전 수정에서 expert의 최소 2m와 이득 .65를 초기값으로 채택했다. 다만 expert는 경로의 기존 점을 순서대로 검사해 반경 밖 첫 점을 고르고, 현재 VLDrive는 선분 위 정확한 반경 교차점을 보간한다. 경로 점 밀도도 같다고 확인하지 않았다. 같은 파라미터 숫자만으로 같은 제어 동작을 보장할 수 없다. 이전 이상적 원형 경로 실험은 이번 실제 예측 점 간격·잡음에서 2m가 적절하다는 근거로 충분하지 않았다.

## 표시 문제와 추가 관찰

차량 그림의 길이/폭은 제공받은 4.635m/1.892m와도 다르고, 후륜 또는 GPS 기준을 명시한 차체 외곽이 아니다. 현재 offset=0 때문에 조향식은 현재 pose를 후륜처럼 쓰지만 그림은 그 pose를 차체 중심으로 사용한다. 예를 들어 실제 pose가 후륜이라면 차량 앞끝은 `wheelbase+front_overhang=3.845m` 앞이므로 현재 그림과 다르다. 실제 pose 기준을 확인해 제어와 그림을 함께 맞춰야 한다.

추가로 이번 로그에서 수신 휠각은 요청 휠각과 부호가 반대이며 약 1송신 tick 뒤에 일치하는 패턴이 보인다. 약 50ms 이전 요청과 비교하면 같은 부호 MAE=9.4815°, 부호 반전 MAE=.1706°였다(943 tracking 송신 중 시차 .3초 미만인 유효 쌍). 따라서 현재 화면의 요청/수신 값은 같은 부호 기준으로 표시되지 않는다. 이 관찰만으로 실제 역조향이라고 결론 내리거나 송신 부호를 바꾸면 안 된다. 수신 표시에 대한 좌표 부호 확인이 필요하다.

## 후속 수정의 초점

1. GPS/모델 pose와 후륜·차체 외곽의 기준을 확인하고 화면과 계산을 일치시킨다.
2. 실제 속도만으로 최소 2m에 고정되는 규칙을 재검토한다. 신경망 첫 점까지의 거리와 예측 경로의 형태를 고려해야 한다.
3. 현재 기록에서 4m와 5m를 우선 비교 후보로 삼을 수 있으나, 직진과 회전의 실제 경로 편차를 확인한 뒤 선택한다. 이번 계산만으로 최적값을 확정하지 않는다.
4. 현재 주행 설정은 분석을 위해 그대로 유지했다.
