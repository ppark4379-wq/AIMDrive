# 지나친 예측 구간 제외 및 전방 목표점 선택

2026-09-22. 사용자가 승인한 다음 단계: 이미 지나친 추론 목표점을 사용하지 않고 남은 경로를 추종하도록 변경.

## 구현

`control/steering_target.py`에서 현재 차량 좌표로 변환된 원본 다섯 예측 점을 사용한다.

1. 각 선분에 차량 원점을 투영하고 가장 가까운 투영점을 선택한다. 길이 0인 중복 선분은 건너뛴다. 같은 거리이면 원래 순서상 이른 선분을 선택한다.
2. 투영점 이전의 경로를 조향 목표 후보에서 제외한다.
3. 목표 거리를 `clip(max(speed,0) × 0.8초, 4m, 12m)`로 계산한다. 속도는 현재 차량 상태의 m/s.
4. 투영점 이후 경로 순서대로, 전방 좌표 0.5m 이상이고 차량과의 직선거리가 목표 거리 이상인 첫 점을 선택한다. 구간 내부는 선형 보간한다.
5. 첫 유효 점이 이미 목표 거리보다 멀면 그 점을 사용한다. 원점을 경로에 추가하거나 경로 끝을 외삽하지 않는다. 전방 길이가 부족하면 거리를 임의로 줄여 가까운 점을 선택하지 않는다.
6. 새 목표점 방향 오차를 기존 LMDrive PID에 입력한다.

`configs/vldrive_control.json` → `lateral.target`에서 관리한다. 초기 실험값이며 최적 주행 파라미터로 검증한 값은 아니다. 원본 비교용 `first_two_midpoint` 모드를 보존하고 기본값을 `remaining_path`로 변경했다.

기존 현재 좌표 변환, 모델·navigation, LMDrive P/I/D/이력 길이/배율, 종방향 expert 코드·파라미터, 조향 10Hz·종방향/UDP 30Hz는 유지했다. Global path는 조향 경로로 사용하지 않는다.

## 유지 명령과 경로 부족

조향 출력 유지 중에도 30Hz마다 현재 입력 경로가 충분한지 검사한다. 유지 중인 목표점의 월드 위치를 현재 차량 좌표로 다시 변환하고, 전방 0.5m 미만으로 넘어가면 정규 조향 주기를 기다리지 않고 즉시 목표점을 재선택한다. 기존 예측 나이 1.25초 제한과 센서/pose/ACK 유효성 검사는 그대로다.

목표 거리까지 앞쪽 경로가 없으면 `insufficient_remaining_path`로 기존 정지 명령(가속 0, 브레이크 1, 조향 0)을 사용한다. 유효 입력이 다시 도착하면 기존 PID reset 이후 재시작한다. 별도 완만한 감속 프로파일은 이번 범위에 추가하지 않았다.

거리 하한은 조향을 갱신하는 순간 기준이다. 갱신 사이 차량이 이동하면 유지 목표점 거리는 4m보다 작아질 수 있다. 뒤쪽 목표점은 계속 사용하는 대신 재선택한다.

### 종방향 보존의 정확한 의미

유효 경로가 연속된 100회 자동 테스트에서는 이전과 가속·브레이크·목표 속도가 정확히 같았다. expert 종방향 코드와 게인은 수정하지 않았다.

하지만 실제 기록 재생에서는 추가 정지 후 기존 PID reset이 일어난다. 그러므로 이후 공통 tracking tick에서도 가속 최대 차이 **0.1**, 브레이크 최대 차이 **0.288741**, 목표 속도 차이 **0m/s**가 있었다. 정지 override tick 자체는 가속 0 / 브레이크 1이다. 이번 결과를 모든 종방향 출력이 동일하다고 설명하면 안 된다.

## 화면과 실행

화면 목표 설명을 '남은 예측 경로'로 바꾸고, 선택한 waypoint 구간, 목표 거리와 실제 거리를 표시한다. `control.jsonl`에는 `target_segment_fraction`, `path_progress_m`, `remaining_path_m`, `target_path_distance_m`도 기록한다. 선택 관련 값은 마지막 조향 갱신 시점의 값이고, 실제 목표점 위치·거리는 현재 pose로 갱신된다.

WSL lmdrive 환경의 VLDrive 폴더에서 기존 추론을 종료하고 실행:

```bash
python inference/realtime_vldrive.py
```

현재 config는 새 목표 선택과 UDP 제어가 활성화돼 있다. 이번 작업은 코드·자동 테스트·기록 재생 검증이며 실제 MORAI 폐루프 주행은 실행하지 않았다.
