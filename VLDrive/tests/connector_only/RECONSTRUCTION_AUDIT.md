# 복원 모듈과 MEFA 정보 전달 경로 검사

> 이후 복원 모듈만 추가 학습한 결과는 `RECONSTRUCTION_TRAINING_RESULT.md`에 있다.
> 아래 수치는 추가 학습 전 가중치에 대한 감사 기록이다.

기존에 평가한 새 20개 주행/160개 현재 프레임, 동일한 학습 완료 가중치를 사용했다.
모델 구조·가중치·학습 설정은 변경하지 않았다. 실행기는 `audit_mefa_path.py`다.

## 복원 모듈의 입력 활용과 품질

| 조건 | 제거된 토큰의 평균 MSE | 정상 복원이 더 좋은 프레임 |
|---|---:|---:|
| 해당 프레임의 정상 connector 출력 | 0.3140752255 | — |
| connector 출력 특징을 0으로 대체 | 1.2355352305 | 160/160 |
| 다른 종류의 주행 장면 출력으로 대체 | 0.3908464825 | 159/160 |
| 학습 데이터의 토큰 위치별 평균 특징만 출력 | 0.0869150953 | 0/160 |

앞의 세 조건은 같은 복원 모듈을 사용하며, 복원 정답·마스크·선택 위치는 같다.
다른 장면도 원래 프레임과 같은 위치/개수의 마스크로 connector를 실행해 padding이나
토큰 개수 차이가 입력 변경과 혼동되지 않게 했다.
평균 특징 기준은 학습 32개 시퀀스의 현재 프레임만 사용해 106개 위치별 256차원 평균을
만들었다. 검증 특징은 기준값 생성에 포함하지 않았다. 동일한 제거 위치에 대해 오차를 비교했다.

**복원 모듈은 입력에 의존하지만, 단순 위치별 학습 평균보다 복원 품질이 낮다.**
입력 활용 여부와 충분한 복원 품질은 다른 조건이다. 현재 상태에서는 복원 모듈을
신뢰할 만한 MEFA 성능 판정 도구로 간주할 근거가 부족하다.
이전 과거 0 비교의 양수 delta는 이 특정한, 아직 미흡한 복원 모듈에서의 상대 변화로 한정한다.

## 과거 특징 및 Q-Former 경로

실제 tensor hook과 직접 계산 결과를 비교했으며 160개 시퀀스에서 실패 항목은 없었다.

- Query embedding: 정규화된 현재 특징에서 CCDP 선택 인덱스로 모은 뒤 projection한 값과 일치.
- Query mask: 실제 선택 슬롯과 padding 구분이 일치.
- 과거 평균: 각 프레임에서 현재를 제외한 직전 최대 10개 정규화 특징의 직접 평균과 일치.
- 강화 특징: 현재 정규화 특징 + temporal MLP 출력과 일치.
- Q-Former의 encoder memory 및 모든 cross-attention K/V projection 입력:
  모두 강화된 전체 현재 특징과 일치.
- 정상 과거/과거 0 비교에서 초기 Query는 동일하며, K/V 입력과 최종 선택 토큰 출력은 변화.
  내부 attention의 Query는 이후 self-attention/정규화를 거치므로 처음 Query embedding과
  같다는 주장은 하지 않는다.
- 복원 입력을 직접 구성한 결과가 전체 connector forward의 복원 결과와 일치.
- 제거된 원본 특징 값을 변경해도 복원 예측은 그대로여서, 제거된 정답이 복원 입력으로
  직접 새어 들어가지 않는 것을 확인.

정상 과거/과거 0에서 평균 절댓값 변화량은 K/V 입력 0.11233,
Q-Former hidden 0.02685, 선택된 최종 출력 0.01574였다.
이는 정보가 전달된다는 증거이며, 좋은 정보라는 성능 증거와는 구분해야 한다.

## memory bank 표현의 정확한 범위

현재 temporal encoder에는 호출 사이에 프레임을 저장하는 영속 memory bank가 없다.
입력 `[B,T,N,C]` 시퀀스 안에서 과거 10프레임을 평균하는 stateless 방식이다.
이번 데이터 loader는 각 입력에 과거 10개와 현재 1개를 함께 제공했다.
현재 프레임 1개만 따로 호출하면 history가 0이 되는 것도 확인했다.

별도 13프레임 구조 검사에서 현재 프레임 제외, 미래 프레임 제외,
10프레임보다 오래된 특징 제외가 모두 통과했다.
따라서 이번 결과는 오프라인 시퀀스 입력의 검증이며,
실시간 수신 프레임의 저장·삭제·에피소드 전환 버퍼가 구현/검증됐다는 뜻은 아니다.
