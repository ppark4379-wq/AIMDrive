# 수동 후보 경로 기록

Expert(main.py)는 종료하고 ROS bridge는 유지합니다. MORAI를 Manual-Keyboard,
D 기어로 설정한 뒤 직접 운전합니다. 기록기는 차량 제어 명령을 보내지 않습니다.

Ubuntu 20.04 WSL 터미널에서 실행:

```bash
cd /mnt/c/Users/dydwn/AIMDrive/MoraiDrive/expert
source /opt/ros/noetic/setup.bash
source devel/setup.bash
/usr/bin/python3 record_static_route.py --check
/usr/bin/python3 record_static_route.py straight
```

정지선 부근에서 Enter를 눌러 기록을 시작합니다. 장애물을 지나 전역경로에
복귀한 곳까지 직접 운전하고 Ctrl+C 한 번으로 저장합니다. 같은 시작점에서
`right_01`, `right_02` 등의 새 이름으로 반복합니다. 기존 파일은 덮어쓰지 않습니다.
순간이동은 기록 종료 후에만 하세요. 위치 점프, 시각 역행, 2초 이상의 수신
공백이 생기면 기록이 중단되며 저장된 부분 경로는 완주 경로로 사용하면 안 됩니다.

## 좌표 및 저장 형식

- `/Ego_topic`의 `morai_msgs/EgoVehicleStatus.position.x/y/z`를 그대로 저장합니다.
- 단위는 ENU 미터이며 기존 Expert의 map 좌표와 동일합니다. 원점 이동,
  UTM 변환, 범퍼/차축 오프셋, 지면 높이 보정을 하지 않습니다.
- 사진의 시작 위치는 대략 `(-59.65, -159.06, 29.96)`입니다. 기본적으로 XY가
  `(-59.65, -159.06)`에서 5m 이내인지 확인합니다. Z는 실제 수신값을 보존합니다.
- `heading_deg`는 수신 각도, `yaw_rad`는 기존 Expert와 동일한 라디안 변환입니다.
- `후보전역경로/<이름>.csv`: `x,y,z,heading_deg,yaw_rad,s_m,speed_mps,source_stamp_s`.
- 기본 샘플 간격 0.2m, 마지막 위치도 보존합니다. 변경: `--spacing 0.1`.
- 다른 시작점은 `--start-x X --start-y Y`로 지정합니다. 경로 자체를 이동시키지 않습니다.

## 기록 기반 사전 계획

`routes.json`에 선택된 6개 파일을 정적장애물 구간에서 사용합니다. `right_4.csv`와
미완성 `right_06.csv`는 제외하고 06은 `right_06_retry.csv`를 사용합니다. 원본 CSV는
보존하며 로딩 시 04의 초반 후진 5개 점, 06 재기록본의 1개 점을 제외합니다.
05에는 후진 구간이 없습니다. ENU 원점은 이동하지 않습니다.

정지선 접근 구간에서 정적 GT가 있으면 먼저 정지 상태를 확보하고 백그라운드에서
완주 경로를 계획합니다. 계획이 끝나기 전에는 진행하지 않습니다. 기록 경로를
그대로 쓸 수 없으면 전진 방향 그래프 탐색으로 안전한 부분들을 연결합니다.
연결부는 위치/접선/곡률을 맞추고 차량 길이 4.635m, 폭 2m 및 기존 안전 여유로
OBB 충돌검사합니다. 전역경로 복귀와 이후 10m 진행 경로까지 미리 확보합니다.
복귀 상한 지점은 ENU `(-59.97, -116.70, 28.37)` 부근입니다. 마지막 20m에서
장애물을 지난 뒤 전역경로로 이어지는 부드러운 복귀 연결을 미리 검사합니다.
연결부는 위치/접선/곡률을 맞추며, 기존 회피 앞부분은 유지합니다. 복귀가 먼저
완료되고 실제 횡오차 0.3m 이내, 방향 오차 10도 이내이면 상한 지점까지 기다리지
않고 전역경로를 사용합니다. 새 장애물이 있으면 조기 전환하지 않습니다.
XY 기준으로 판단하며 Z를 보정하지 않습니다. 신호/장애물 감속은 그대로 유지합니다.
전역경로가 일시적으로 없으면 미리 확보한 전역경로 구간을 유지합니다.
회피에서 전역경로로 전환될 때 목표속도 증가를 `STATIC_TARGET_ACCEL=1.2 m/s2`로
제한하고 Pure Pursuit 추종 거리를 점진적으로 늘립니다. 제동 요청은 지연하지 않습니다.
복귀 연결은 차체에 추가 0.2m 추종 여유를 확보합니다. 허용 경계는 차체 네 변을
5cm 간격으로 교차 계산하며, 드문 측면 샘플 때문에 생기던 경계 함몰을 제거했습니다.
정렬 완료 전에는 `TRACKING_SPEED=2.0 m/s`(7.2km/h) 이하로 추종하여 굽은 구간에서
조향 지연을 줄이고, 전역경로 전환 후 위 가속 제한으로 자연스럽게 속도를 높입니다.
종료 Y 좌표만 지났다고 복귀를 강제하지 않으며 실제 위치/방향과 충돌 여부를 확인합니다.

선택 후에는 세계좌표 경로를 유지하므로 로컬 전역경로가 잠시 없어져도 회피를
계속합니다. 새로운 장애물이나 추종 이탈은 정지 사유이며, 움직이면서 다른 후보로
계속 바꾸지는 않습니다. 신호/동적장애물 제어는 유지됩니다. RViz에는 선택 경로
하나와 `STATIC: RECORDED` 상태 및 선택된 파일 이름이 표시됩니다.

주의: 도로 경계는 지도 차선이 아닌 **수동 기록의 차체 통과 범위**로 제한합니다.
기록 자체가 도로 밖이라면 자동으로 판별할 수 없습니다. 실제 MORAI 저속 검증이
필요하며, 이 도로의 북향 정적장애물 구간 전용입니다.

오프라인 검사(차량을 움직이지 않음):

```bash
python check_static_routes.py
```

이 검사는 저장된 장애물 장면을 사용하며 현재 MORAI 장면과 다를 수 있습니다.
새 설정 적용은 Expert를 종료하고 `python main.py`로 다시 실행합니다.
선택 경로는 프로세스 메모리에만 보존됩니다. 회피 도중 종료했다면 정지선 접근
위치로 차량을 되돌린 뒤 시작하세요. 중간 자세에서 새 연결을 검증하지 못하면
`no_complete_route`로 정지하며, 안전 검사를 생략해 출발하지 않습니다.
